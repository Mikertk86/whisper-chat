# Whisper Android release

Whisper is a private messenger build based on SimpleX Chat, prepared for Michal's public test distribution.

## Android package

- Application ID: `chat.whisper.app`
- App name: `Whisper`
- Release artifacts: `whisper-arm64-v8a-release.apk`, `whisper-armeabi-v7a-release.apk`
- Support contact in app: Hermes

## Download

Use GitHub Releases for official public APK downloads. Verify SHA-256 checksums from the release assets before installing.
