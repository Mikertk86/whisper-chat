# Whisper Android release

Whisper is a private messenger build based on SimpleX Chat source code, prepared for public Android distribution by Michal/Mikertk86.

## Official download

- Repo: https://github.com/Mikertk86/whisper-chat
- Releases: https://github.com/Mikertk86/whisper-chat/releases
- Latest: https://github.com/Mikertk86/whisper-chat/releases/latest
- Current release: https://github.com/Mikertk86/whisper-chat/releases/tag/whisper-v6.5.6-official-1

- Application ID: `chat.whisper.app`
- App name: `Whisper`
- Release artifacts:
